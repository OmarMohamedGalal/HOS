## About the Project

**HyperOS Super Icon Widgets** is an Android application designed to enhance the HyperOS 3 home screen experience by allowing users to customize app icon widgets in different sizes.

The goal is to provide more flexibility over home screen layouts while maintaining the familiar HyperOS visual style.

## Features

- **Multiple Widget Sizes** – Choose between different widget dimensions:
  - `2 × 2` – Square widget.
  - `2 × 1` – Horizontal widget.
  - `1 × 2` – Vertical widget.
- **HyperOS 3 Experience** – Designed around the HyperOS 3 ecosystem.
- **Home Screen Customization** – Create a more personalized home screen layout.
- **Simple Interface** – Easy-to-use controls for configuring widgets.
